# Неделя 1 · Чеки поездки -> кто кому должен

Сдача по заданию недели 1 рабочей группы хакатонов AI Mindset. Поездка синтетическая: Тбилиси, 11-13.09, пятеро, RUB и GEL с курсом на дату, 37 сообщений, 13 чеков, 2 возврата.

| Файл | Что это |
|---|---|
| `00_control_facts.md` | пять контрольных фактов, записаны до генерации данных |
| `01_chat.md` | групповой чат, M01-M37 |
| `02_receipts.md` | чеки и возвраты, R01-R13 |
| `03_table.md`, `03_table.csv` | траты и доли, балансы, план переводов |
| `04_report.md` | ответы на пять вопросов со ссылками на сообщения и чеки, спорное |
| `settle.py` | расчёт и проверка фактов, стандартная библиотека Python 3 |

## Как повторить

```bash
python3 settle.py   # пересобирает 03_table.*, падает, если контрольный факт не сошёлся
```

## Как делалось

1. Записаны контрольные факты.
2. Агент сгенерировал чат и чеки под них, с ловушками: дубль чека (фото + «скинул чек»), пропуск ужина, отказ от бань с возвратом, возврат за квартиру, перевод в поездке, личная покупка, обещание без суммы.
3. `settle.py` посчитал и подтвердил все пять фактов.
4. Второй агент пересчитал вслепую по чату и чекам и получил те же ответы.
